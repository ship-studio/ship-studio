# Harbr release notes

## What's New in v0.1.0

- **Independent Harbr identity** — New product name, application identifiers,
  binaries, repository links, artwork, and platform icons.
- **Self-hosted browser workspace** — Authenticated HTTP, event, file, and PTY
  transports bring the development workspace to Linux and the browser.
- **Desktop and browser parity** — Coding agents, previews, Git workflows,
  project organization, and deployment tools share one current upstream base.
- **Private by default** — Upstream telemetry and remote error reporting are
  removed. Product events stay in local structured logs.
- **Safe legacy migration** — Supported JSON state can be copied once into
  Harbr-owned storage without modifying or overwriting legacy data.
- **Updater paused** — Update checks and updater bundles remain disabled until
  Harbr has its own signing key.
